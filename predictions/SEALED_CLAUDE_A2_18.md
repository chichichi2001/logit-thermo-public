# Claude の封をした予想：A2-18（罰をかけていない出力だけから、罰の効きを予言できるか）

## 問い

- **XQ1（h*、|h| ＝ 0.37〜0.79）**：「予言どおり（2 割の内）」。確からしさ 60%。中央値 ρ ≈ 1.1。
  - 外れるなら「はっきりしない」（区間が 1.25 をまたぐ）。
- **XQ2（2h*、|h| ＝ 0.75〜1.57）**：「予言より大きく効く」45%、「はっきりしない」35%、「予言どおり」20%。中央値 ρ ≈ 1.35。
  - 理由：罰（h ＜ 0）をかけると候補の確率 q' が下がり、ln q' の h による傾き (1 − q')/T は q' が小さくなるほど 1/T に近づいて大きくなる。結晶の中（q ≈ 1）では h ＝ 0 での傾きがほぼ 0 なのに、罰で q' が下がると急に効き始め、溶けやすさが 1 次の予言より速く増える。だから罰の向きでは、応答は h について 1 次より強くなる（上に反る）と読む。8.39 で大きな場で効きが縮んだのは、写しを増やす向き（h ＞ 0、q' → 1）だったので、向きが逆。
  - G-pre でも h ＝ −0.3 の ρ（1.00）が ＋0.3（0.96）より少し大きく、同じ向き。
