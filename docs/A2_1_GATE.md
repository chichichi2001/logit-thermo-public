# A2-1 ゲート：一歩の「融点」は、文献の崩れる温度と同じ順に並ぶか

## 1. 問い

一歩の分布を「頭の相」（順位 1〜99）と「裾の相」（順位 100〜）に分けると、温度を上げたときに裾の確率が頭を追い越す温度 **T_half** がある。確率は exp(−自由エネルギー ÷ 温度) に比例するので、T_half は**頭と裾の自由エネルギーが等しくなる温度**で、化学の**融点**と同じ考え方（融点 ＝ 融解熱 ÷ 融解エントロピー）。

**この一歩の融点は、生成した文章が崩れる温度（文献の T_c）と、どう関係するか。** 3 つの対立：

- **(i) 一致**：T_c ≈ T_half（一歩の融点で文章が崩れる）。
- **(ii) 一歩が高い**：T_c < T_half（フィードバックで、一歩の予言より早く崩れる）。
- **(iii) 一歩が低い**：T_c > T_half（文章は一歩の予言より粘る）。

T_c は文献の値で、**生成した文章から測ったもの（分布の外）**。T_half は一歩の分布から計算する。だから A1 のような恒等式にはならない（§2 の罠チェック）。

## 2. 罠チェック（LOGIC_MAP §3）

1. 予言に使う量（T_half：一歩の分布）と、予言する量（T_c：文献、生成した文章）は別のもの。✓
2. T_half の計算の確かめ（`scripts/a2_core.py`、合成データ）：純粋なべき（a = 1.4、語彙 151,665）で T_half = 1.325（H = 100）。1 位の logit を +5 で 1.650、+10 で 2.073（レビュー役の計算と一致）。純粋なべきでは T_half ≈ 0.95 × a（a = 0.8・1.0・2.0 で 0.757・0.947・1.893）。**T_half は a と頭の強さの両方で動く。**
3. 新鮮な目のレビュー：予想を頼む前に行う（§10）。

弱いところ（先に書いておく）：

- 文献の 3 つ（§4）は、崩れの決め方・プロンプト・モデルの版がばらばら。**値ではなく、順番・大きさによるか・(i)〜(iii) の大まかな区分で判定する。**
- 僕らの位置は、モデル自身が**貪欲法**（いつも 1 位を選ぶ）で書いた続き。迷いの少ない位置に偏るので、頭が強めに出て、T_half は高めに出るかもしれない。文献は温度をつけて生成した文章。

## 3. 測り方

- 1 行（1 位置）ごとに、使う番号（`metadata.json` の `tokenizer_len` 未満）の logit を大きい順に並べる。
- **T_half(H)**：順位 H 以降の確率の合計が 1/2 を超える最低の温度。温度の格子は 0.05〜20 を対数で 241 等分。log(裾 ÷ 頭) が 0 を横切る点を、対数温度で直線補間。最低温ですでに裾が上の行は「低温側に張り付き」、最高温でも頭が上の行は「高温側に届かない」として外し、割合を記録。
- **本命は H = 100**。H = 30・300 は記録（切れ目を変えても結論が変わらないかの確かめ）。
- **モデルの T\***：T_half（H = 100）の行の中央値。95% 区間は、プロンプト（12 個）単位のブートストラップ（2,000 回、乱数の種 20261027）。
- 記録として、A1 と同じ a_loc・a_win・g・c・h・T_C・T_on_tail も計算する（`scripts/a1_core.py` をそのまま使う。窓は語彙 5 万でも順位 10,000 まで入る）。

## 5. 判定

- **J1（順番、Pythia）**：T\*(70M) < T\*(160M) か。区間が重ならなければ「はっきり」。
- **J2（大きさ、Qwen2.5）**：素の 4 モデルの T\* がすべて、その 4 つの中央値の ±10% に入れば「そろう」、入らなければ「ばらつく」。指示調整の 4 モデルも同じ決め方で別に判定する。

## 10. 新鮮な目のレビュー（2026-10-27、経緯を知らないサブエージェント）

- **良い点**：分布の外の量（文献の T_c）と比べるので、A1 のような恒等式にはなっていない。弱いところを先に書いている。合成データで手順を確かめた。
- **「融点」は名前だけ**：裾と頭の確率の比は定義から exp(−ΔF/T) なので、「自由エネルギーが等しい温度」は「上位 99 位の確率が半分になる温度」の言い換え。融点 ＝ ΔH/ΔS の読みが効くのは ΔH・ΔS が温度によらずほぼ一定のときだが、確かめていない。中身のある仮説は「一歩の確率の半分が裾へ流れる温度で文章が崩れる」という機構の話。
- **J1 は熱力学と関係なく当たりうる**（大きいモデルほど頭が強い、だけで当たる）。しかも文献の 70M と 160M の T_c は決め方が違うので、T_c の順番そのものが確かでない。
- **J2 は T_c の値を使わない**。
- **J3 は走らせる前に見当がつく**：A1 の a ≈ 1.4 と h（中央値 2.8〜3.5）を合成に当てると T_half ≈ 1.7〜1.9 なので、Qwen の比は ≈ 1.5（「一歩が高い」）になりそう。しかも比が 1.25 を超えても、原因が「フィードバック」「貪欲法の位置の偏り」「1/2 という閾値の選び方」のどれか区別できない。
- **閾値の自由度が大きい**：裾の取り分の閾値を 0.1・0.5・0.9 にすると、T は 0.97・1.33・1.95（a = 1.4 の純粋なべき、Claude も確かめた）と約 2 倍動く。切れ目 H（30・100・300）の影響は小さい（1.24・1.33・1.40）。128 歩の文章なら、一歩の裾の取り分が 0.1 でも崩れうる。
- その他の穴：端に張り付いた行を外すと中央値が偏る（±∞ として中央値に入れるべき）。Qwen を上位 2 万位から計算すると T_half が高めに出る（1.325 → 1.394）。ガウス型の logit（σ = 2.49）でも T_half は出る（Claude の計算で 0.80）＝べき型の裾がなくても定義できてしまう。
- 直すこと（優先順）：Qwen は語彙全体で計算／端は ±∞ で中央値に／閾値 0.1・0.9 と行ごとの 10% 点も記録／「融点」は仮の名前と明記し、(ii) をフィードバックと読まない／「全モデルで T* ≈ 1」「A1 の a・h からの値」を対照の予言として先に書く。
- 削るもの：J1 は記録へ、指示調整版の J2 も記録へ、step 0 と A1 の量の一式は削る（a と h だけ残す）。
