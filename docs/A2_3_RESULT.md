### 参考の判定が 0.0001 で決まったことについて

決まりどおり、参考の判定は「一般的ではない」と書く。ただ、この差（0.930111 − 0.93 ＝ 0.00011、0.012%）は、この測り方で意味のある桁よりずっと小さい。比べるための目安：
- 同じ記事・同じ種で GPU を替えただけで、T_0 は 0.4% 動いた（A100 の確かめ）。
- ε を A2-2 の中央値 0.194 に固定すると、Qwen2.5-7B の T_0 は 0.857 になる（記録、§4）。
- Qwen2.5-7B の区間の半分の幅は約 6%。

なので、参考の判定の「一般的ではない」は「点が帯の上の端にちょうど乗った」と読むのが正確で、「帯から外れた」証拠にはならない。

## 6. 何が言えて、何が言えないか

**言えること**
- 5 つの新しい条件で、T_0 が帯 [0.78, 0.93] の外にはっきり出た例は 1 つもなかった（「帯の外」0）。
- 点の値は 5 つとも 0.82〜0.93。A2-2 と合わせると、4 家族・12 の組（大きさ 0.5B〜7.6B、ニュースとコード）で 0.80〜0.93。
- コードは人の文章よりずっと予測しやすいのに、T_0 を帯の上に押し出さなかった（区間の上の端は 3 つとも 0.934 以下）。
- 温度計 T_cal は、ここでもほぼ 1 に張り付いた。

**言えないこと**
- 「T_0 は一般的に 0.85 付近」：本命の判定が「はっきりしない」なので言わない。区間が広くて、帯に入るかを決めきれない条件が 3 つあった。
- 「大きいモデルほど T_0 が上がる」：Qwen の点は 0.858 → 0.910 → 0.930 と上がったが、区間は重なっている。
- 「コードでは T_0 が上がる（下がる）」：動きはモデルでばらばらで、区間の中に収まる。
- コードの結果は、AI の書いたコードが混ざっている分（§10 の注意 1）と切り分けられていない。
