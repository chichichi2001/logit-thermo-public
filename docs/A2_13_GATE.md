## 3. 問いと決め方

- **PQ1（Pythia の大きさで、塩の効き S_AL はどう変わるか）**：b の点と区間で：
  - 「大きいほど上がる（塩で A が溶けやすくなる）」：区間の下 > 0 かつ b ≥ 0.10
  - 「大きいほど下がる（塩で A が溶けにくくなる）」：区間の上 < 0 かつ b ≤ −0.10
  - 「ほとんど変わらない」：区間が −0.10〜＋0.10 に収まる
  - それ以外、または選び直しで b が出ない回が 1 割を超えたら「はっきりしない」
- **PQ2（家系の差 D：SmolLM2 と Pythia で、塩の効きは違うか）**：D の点と区間で：
  - 「SmolLM2 のほうが溶けやすい（Pythia の家系の癖らしい）」：区間の下 > 0 かつ D ≥ 0.15
  - 「Pythia のほうが溶けやすい」：区間の上 < 0 かつ D ≤ −0.15
  - 「同じくらい（家系の癖ではなさそう）」：区間が −0.15〜＋0.15 に収まる
  - それ以外、または選び直しで D が出ない回が 1 割を超えたら「はっきりしない」

## 6. 承知している弱いところ

- **区間が広い**：A → L の回数が少ないので、モデル 1 つの S_AL の区間は、サンプル 4 でも ±0.15〜0.2 くらいと見込む。このため、傾き b の区間は ±0.12〜0.15、家系の差 D の区間は ±0.11〜0.14 くらいになり、PQ1 の「ほとんど変わらない」（±0.10 に収まる）と PQ2 の「同じくらい」（±0.15 に収まる）は、ほぼ出ない（D の点が ±0.01〜0.04 の中にないと出ない）。本当に差がないときの答えは、たいてい「はっきりしない」になる。実際には、どちらの問いも「＋の向き」「−の向き」「はっきりしない」の 3 つから決まる（新鮮な目のレビューの指摘、2026-10-30 18:5x）。
- **温度とモデルの融点の位置**：S_AL は 0.4〜0.7 の平均で、モデルごとに融点（0.5〜0.7 くらい）が違う。融点に対してどこを見ているかがモデルでずれる。温度ごとの回数も残す。
- **大きさと家系の取り違え**：Pythia と SmolLM2 は学習データ・語彙・学習の長さが違う。PQ2 で差が出ても、理由が家系の作りか学習データかは分からない。
- **2.8B だけ分けて生成**：偽薬の「残りの借り」は 20 本ずつで配られる（禁止の割合は同じ 30%）。
- 小さいモデル（70M・135M）は結晶が多く、液体にいる歩が少ない。
- 境（0.10・0.15）は、A2-10 の 3 つの値を見たあとで決めた（新しいデータは見ていない）。
- 温度を 0.75・0.8 まで伸ばさないので、2 つの状態の T_m は、融点が 0.65 より上のモデルでは出にくい（記録だけ）。
