- **Qwen2.5 と Qwen3 の T_0 は近い**（0.895 と 0.916）。同じ会社の「近い乳」は近いところに並んだ。SmolLM2 と Pythia も近い（0.801 と 0.838）。

## 5. 後知恵（確かめていない）

- **融点は乳の種類で決まる、はかなり強く出た**。家族の差（0.80〜0.92）が、家族の中の幅（多くは 2〜4%）よりずっと大きい。ただし家族＝データとは言い切れない（作り・トークナイザー・学習の長さもいっしょに変わる）。
- **大きさで固まり方が浅くなる、は Pythia だけの話だったかもしれない**。新しい 3 家族では、大きさと深さの並びがそろわなかった。Qwen の 2 家族は小さくても大きくても温度 0.7 で深く固まる（−1.8〜−2.9）。
- **鋭く溶ける家族と、なだらかに溶ける家族**：Qwen の 2 家族は傾きが大きい（鋭い融解）。化学では、純粋な結晶ほど融点で鋭く溶け、不純物の多いものや高分子はなだらかに溶ける。ところが A2-2 のガラスの割合は Qwen がいちばん高かった（0.40〜0.57）。「ガラス寄りなのに鋭く溶ける」というねじれがある。
