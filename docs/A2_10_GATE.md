## 2. 測るもの

- **T_m**：A2-8 と同じ決め方（写しの印、中心の窓 32、入口 0.5・出口 0.25、凍る回・溶ける回がそれぞれ 10 回以上の温度で ln K を 1/T に重みつきで当てはめ、ln K ＝ 0 の温度）。使う温度は腕ごとに、点のときの数で決める（濃い偽薬では T_m が下がり、使える温度がずれるため）。熱量計の ΔH は出さない（読み直しをしない）。
- **T_0**：A2-4 と同じ（記事ごとの f の中央値に PAV、交点）。ただし **温度 0.6〜1.05 の 8 つだけ**で出す（A2-7c と同じ格子。A2-7b で低い温度を入れて ε がふくらんだ失敗を繰り返さないため）。ε はモデルごとに、「なし」のこの 8 つの温度で出す。
- 下がり方：y_m ＝ log(T_m(腕) ÷ T_m(なし))、y_0 ＝ log(T_0(腕) ÷ T_0(なし))。
- 傾き：偽薬の 3 本で、原点を通る直線 y ＝ −K × 濃さ を最小二乗で当てはめる。K_m は 3 本とも T_m が出たときだけ、K_0 は T_0 が出た 2 本以上で。
- 区間：記事を選び直すブートストラップ（1,000 回、種 20261117。全部の腕で同じ選び方）。

## 3. 問いと決め方

- **DQ1（偽薬 30% で T_m がどれだけ下がるか）**：モデルごとに y_m（30%）の点と区間で：
  - 区間の上が 0 以上で下が 0 未満 →「はっきりしない（0 をまたぐ）」。区間の下が 0 以上 →「上がる」。選び直しで T_m が出ない回が 1 割を超えたら「はっきりしない」。
  - それ以外は −y_m の大きさで：「ほとんど下がらない（log で 0.05 未満、5% 未満）」「少し下がる（log で 0.05〜0.15、5〜14%）」「かなり下がる（log で 0.15〜0.30、14〜26%）」「大きく下がる（log で 0.30 以上、26% 以上）」。
  - DQ1 の答え ＝ 「はっきりしない」でないモデル 2 つ以上の y_m（30%）の中央値の言葉（2 つ未満なら「はっきりしない」）。
- **DQ2（T_m のほうが T_0 より速く下がるモデルの数、0〜3）**：R ＝ K_0 ÷ K_m。log R の区間（K_m > 0 ≥ K_0 の回は −∞、逆は ＋∞、両方 0 以下は数えない）で：
  - 「T_m のほうが速く下がる」：区間の上 < 0 かつ点の R ≤ 1/1.5
  - 「同じくらい」：区間が log(1/1.5)〜log(1.5) に収まる
  - 「T_0 のほうが速く下がる（海水型）」：区間の下 > 0 かつ点の R ≥ 1.5
  - それ以外、または選び直しで K_m か K_0 が出ない回が 1 割を超えたら「はっきりしない」
  - DQ2 の答え ＝ 「T_m のほうが速く下がる」になったモデルの数。

## 6. 承知している弱いところ

- **「濃さ」と x（溶けたものの割合）の対応が決まっていない**：1 回の禁止がまわりの何トークンを乱すかは、この設計では測れない（同じ状態から禁止あり・なしを分けて生成しないと分からない）。ΔH_col は「x ＝ 濃さ」「x ＝ 量」の 2 通りで出すだけにする。
- **使う温度が腕ごとに違う**：T_m の当てはめの温度の組が腕で違うので、ln K の曲がりがあると、腕どうしの比べに少しずれが入る。
- **偽薬 30% は強い**：3 歩に 1 歩近く 1 位を禁止するので、文章がかなり崩れ、T_0 の交点が格子の外に出ることがある（そのときは T_0 の腕が減り、DQ2 は「はっきりしない」になりやすい）。
- 温度 0.4 は貪欲に近く、そこでの凍る回・溶ける回は少ない。
- 写しの禁止は入れない（結晶を見つける印そのものを禁止するため、T_m が測れない）。
