## 5. 予言と判定（データを見る前に決める）

並び方は順位相関 ρ（スピアマン。同じ値は平均の順位）で見る。**向きの確かさ**は、記事を組にしたブートストラップ（1,000 回、種 20261103。40 本は全モデル共通なので、各回で同じ記事の番号を全モデルに使う）で、ρ が 0 より大きい（小さい）回の割合で見る。各回、読めない点は外し、読める点が足りない回は「向きが出なかった回」に数える。

- **Q1（大きさの軸とガラスの割合）**：log（パラメータの数）と G の ρ。G07 と G_rel のそれぞれで、
  - 点の ρ ≥ 0.9、かつブートストラップで ρ > 0 の回が 95% 以上 →「＋」
  - 点の ρ ≤ −0.9、かつ ρ < 0 の回が 95% 以上 →「−」
  - それ以外 →「なし」
  - 読めない点は外す。残りが 4 点以上なら計算する（線引きは同じ。4 点では「完全にそろった並び」だけが 0.9 を越える）。3 点以下なら「なし」。
  - **言葉**：G07 と G_rel が両方「＋」→「大きいほどガラス寄り」、両方「−」→「大きいほど結晶寄り」、それ以外 →「はっきりしない」。
- **Q2（学びの軸とガラスの割合）**：step と G の ρ（4 点）。G07 と G_rel のそれぞれで、点の ρ ＝ 1 かつ ρ > 0 の回が 95% 以上 →「＋」、点の ρ ＝ −1 かつ ρ < 0 の回が 95% 以上 →「−」、それ以外 →「なし」。読めない点が 1 つでもあれば「なし」。
  - **言葉**：両方「＋」→「学ぶほどガラス寄り」、両方「−」→「学ぶほど結晶寄り」、それ以外 →「はっきりしない」。
- **Q3（大きさの軸と T_0）**：log（パラメータの数）と log T_0 の ρ。線引き・点の外し方は Q1 と同じ（物差しは 1 つ）。言葉は「大きいほど T_0 が高い」「大きいほど T_0 が低い」「はっきりしない」。
- **Q4（学びの軸と T_0）**：step と log T_0 の ρ。線引きは Q2 と同じ。交差しない点が 1 つでもあれば「はっきりしない」。言葉は「学ぶほど T_0 が高い」「学ぶほど T_0 が低い」「はっきりしない」。
- 2.8B の回が止まった（メモリが足りないなど）ときは、大きさの軸は 5 点で計算する（線引きは同じ）。
