## 3. 問い

### XQ24（温度の恒等式は、温度を変えたときの ln K の動きを予言するか）

- 温度ごとの予言：y(T) ＝ ∂ ln K/∂β を、罰の恒等式 g と同じ組み立て（回数ごとの d_i ＝ Cov(n_i, s)/E[n_i]、まとめた共分散）で、s ＝ −Σ_t (U_t(x_t) − U_c,t) として出す（β ＝ 1/T）。罰なしの腕の、その温度の文だけを使う。
- 比べる量：使う温度（両方向の遷移が 10 回以上）のうち、いちばん低い β から高い β までの、測った ln K の差 Δ_meas ＝ ln K(β_max) − ln K(β_min) と、予言の積分 Δ_pred ＝ ∫ y dβ（使う温度での台形の和）。比 ρ_β ＝ Δ_meas ÷ Δ_pred。
  - ファントホッフの直線の傾きではなく差どうしで比べるのは、直線の傾き（7 つの温度の重みつきの当てはめ）と局所の微分は別の量だから。「両端の差 ＝ 微分の積分」は、ln K が曲がっていても厳密に成り立つ（母集団で）。ずれうるのは、台形の近似（格子の間での y の曲がり）、端の温度の数えの少なさ、まちがい、だけ。
  - つまりこれは、罰の確かめ（A2-19）と同じく、厳密な恒等式が実データの数えの上で成り立つかの確かめで、新しい法則を探すものではない。
- 判定：小さい 7 本の ρ_β の中央値。記事の選び直し 1,000 回（種 20261127、7 本で同じ選び方）。出ないモデルが 2 本までなら残りで中央値。
- 言葉（A2-18 と同じ帯 0.8〜1.25）。上から順に当てはめる：「はっきりしない」（選び直しで出ない回が 1 割を超えるか、点か区間が出ない）、「逆向き」（点が 0 未満）、「予言どおり（2 割の内）」（区間が帯の内）、「予言より大きく動く」（区間の下 ＞ 1.25）、「予言より小さく動く」（区間の上 ＜ 0.8）、「はっきりしない」（ほか）。
- 記録：モデルごとの ρ_β と区間、温度ごとの y(T) と、隣り合う温度の差から出した測った傾き。

### XQ25（平衡の読みの言いすぎは、エネルギーの取り方によらないか）

- A2-26 の全文の ρ_E（平衡の読みに対する比、元の分け方）を、ΔE（2 つの状態の、1 歩あたりのエネルギーの平均の差）の取り方を変えて出し直す：
  - (a) U ＝ −log p_1（論文の取り方。A2-26 の 0.69 と一致を確かめる）
  - (b) −z（logit そのもの）
  - (c) T × (−log p_T) ＝ −z ＋ T lse_T（その文を作った温度での −log p に T を掛けたもの。−log p_T そのものは β × (−z ＋ 定数) で、平衡の読みの n ＝ b/ΔE（b は 1/T での傾き）とつじつまが合う「−z ＋ 歩ごとの定数」の形にするには T を掛ける必要がある。掛けないと比が 1/T（1.5〜3 倍）だけ機械的に動く。レビュー 1）
- n ＝ b/ΔE の b（ファントホッフの傾き）は ln K だけから出るので、取り方によらない。変わるのは ΔE だけ。したがってモデルごとに ρ_E(取り方) ＝ ρ_E(a) × ΔE_取り方/ΔE_(a) が厳密に成り立つ。
- ΔE が 0 以下でも n ＝ b/ΔE をそのまま使う（A2-26 の ratios は ΔE ≤ 0 で出ないことにしていたが、ここでは向きが逆になるのを見るため。レビュー 2）。
- −z は、全部の logit に歩ごとに同じ数を足しても、どのサンプリングも変わらない（ゲージ）。だから (b) の ΔE は、サンプリングの過程ではなく、ネットワークの logit の置き方を測る。この問いが言えるのは「論文の U と、ほか 2 つの取り方で、言いすぎが残るか」までで、「どんなエネルギーの取り方でも」とは言えない。
- 判定：小さい 7 本の中央値、記事の選び直し（同じ種）。
- 言葉。上から順に当てはめる：「はっきりしない」（どれかの取り方で、出ない回が 1 割を超えるか、点か区間が出ない）、「向きが逆になる取り方がある」（点が 0 未満のものがある。ΔE の向きが逆）、「言いすぎでない取り方がある」（点が 0.8 以上のものがある）、「どの取り方でも言いすぎ」（3 つとも区間の上 ＜ 0.8）、「点はどれも 0.8 未満」（点は全部 0.8 未満で、区間の上が 0.8 以上のものがある）。
- 記録：取り方ごとの ΔE と n、モデルごと。
