## 3. 何が起きたか（記録）

- **濃い禁止で、T_0 そのものが測れなくなった**。n ＝ 3・2 では、F が温度 0.6〜1.05 のあいだで ±ε の中に収まって交点が出ない（平ら）か、全部の温度で上（格子の外）になった。ブートストラップで交差しない回が増え、決まりの「両方交差 90%」「並べられる回 90%」に届かなかった。
- **温度の格子の下の端（0.6）が近すぎた**：濃い禁止では T_0 が 0.68〜0.74 まで下がり、格子の下の端に近づいた。床・天井の候補として挙げていた「温度の格子の端に張りつく」が実際に起きた。
- **滴定曲線の形は 3 モデルで違った**：
  - Qwen：0.904 → 0.860 → 0.848 → 0.804 → 0.759 → 0.736。濃くするほどなだらかに下がる（ρ ＝ −1）。
  - Pythia：0.859 → 0.853 → 0.838 → 0.778 → 平ら → 格子の外。n ＝ 4 まではなだらか、その先で融点が消える。
  - OLMo：0.804 → 0.782 → 0.794 → 0.773 → 0.680 → 平ら。n ＝ 4 まではほぼ動かず（±4%）、n ＝ 3 で急に 15% 下がる。オーナーの言う〔オーナーの言葉〕形に近い。

## 4. 後知恵（確かめていない）

- **融点が消える ＝ ガラスになった？**：濃い禁止をかけると、どの温度でも「はっきり固まる」と「はっきり溶ける」の入れ替わりがなくなる。融点を持たずにだらだら柔らかくなるのはガラス（アモルファス）の性質。オーナーが A2-5 のこねこねで挙げた「アモルファスならガラス化点」につながる。写しを全部取り上げると、結晶になる道がなくなり、ガラスしか残らない、と読める。
- **緩衝の形が見えたのは OLMo**：薄いうちは受け止め、n ＝ 3 で受け止めきれなくなった。Qwen は緩衝なしでなだらか、Pythia は n ＝ 4 まではなだらかで、そこから先は融点ごと消えた。A2-4 の「Pythia だけが動いた」は、Pythia が n ＝ 4 ですでに曲線の急なところにいたから、と読み直せる。
- **次に滴定するなら**：温度の格子を 0.4 くらいまで下に広げる（濃い禁止で T_0 が下がっても交点が格子の中に残るように）。オーナーの「小数の n」（確率で禁止する）で n ＝ 3〜4 のあいだを細かく見る（OLMo のストンの位置）。
