## 主張

1. 切り詰めつき（Min-p・top-p など）でも、h ＝ 0 での微分は恒等式で出る。ただし q_t は**切り詰めたあとの集合の中での**候補の確率にする。切り詰めた確率は、ちょうど境界の上にトークンがない限り h になめらかなので、∂ log p_t(x_t)/∂h ＝ (c_t − q_t^S)/T。
2. 有限の h では、罰でトークンが境界をまたぐ歩だけが、1 次の予言の外に出る（集合が入れかわると確率が飛ぶ）。
3. Min-p では、歩のすべてのトークンが境界から（温度をかけた logit で）2|h|/T より遠ければ、その歩の集合は変わらない。φ_i ＝ z_i/T − max z/T − ln r は、logit がどれも |h|/T 以下しか動かないと、z_i の項と max の項でそれぞれ |h|/T 以下、合わせて 2|h|/T 以下しか動かないから（PROJECT_A `notes/MARGIN_STABILITY.md` の定理 1 と同じ。短いので Claude が自分で確かめた）。割る型の罰では、logit の動きは見たことのあるトークンで |z|(θ − 1) 以下（正の logit では |z|(1 − 1/θ)）なので、δ はそれで置きかえる（生の logit が大きいので、条件はきびしくなる）。
4. 運ぶときの注意（別の研究の安全の決まり の心配と同じ種類）：q_t を切り詰める前の確率のままにすると、意味のずれた式になる。

## 作り物での確かめ（`scripts/check_truncated_identity.py`、厳密な数え上げ）

- 作り物：語彙 5、書き出し 3 トークン、続き 5 トークン（5^5 ＝ 3,125 通りを全部数える）、温度 0.7、直前 2 トークンで決まる乱数の logit。写しの候補は論文と同じ作り（直前の 2 トークンのあとに、書き出しを含めて前に続いたトークン）。Min-p は r ＝ 0.12、top-p は 0.8。
- (1) h ＝ 0 での微分：12 通り（足す型・割る型 × 切り詰めなし・Min-p・top-p × 統計 2 つ）すべてで、数え上げた E[Y] の中心差分と、恒等式（切り詰めた q）が 6 桁まで一致。切り詰める前の q を使うと、Min-p・top-p で 4〜27% ずれ、top-p の 1 つでは符号まで逆になった（−0.00024 に対して ＋0.0032）。
- (2) 有限の h（Min-p、足す型、候補を選んだ回数）：集合を h ＝ 0 のまま固定した「なめらかな続き」と、実際の E[Y](h) を比べると、h ＝ −0.10 までは差が 0（1 次の予言との比 1.00〜1.02）。h ＝ −0.15 で集合の入れかわりが始まり、差 −0.012（1 次の予言 −0.029 の 4 割ほど）が一度に加わる。入れかわりがまれでも、効きは大きくなりうる。
- (3) マージンの条件（2|h|/T）を満たす歩で集合が変わった例は 0（どの h でも）。条件は十分条件で、h ＝ −0.10 では 14% の歩が条件を破っていたが、実際に変わった歩はなかった（控えめな条件）。
- 読み：主張 1 と 3 は作り物で確かめられた。主張 2 の「入れかわる歩の割合が小さければずれも小さい」は言えない。入れかわりが起きると、そこから先の文がまるごと変わるので、まれでも効きが大きい。言えるのは、ずれの絶対値が「どこかの歩で集合が入れかわる文の確率 × Y の幅」以下、という粗い上限まで。論文の文はこの範囲で書いた。

## 追記（2026-11-03 13:1x JST、ほかの repo の定理を横断して探した調べ役の指摘と、その確かめ）

- 主張 3 の条件 2|h|/T は正しいが 2 倍きびしすぎた。足す型の罰は logit を 0 か h/T の同じ向きにしか動かさないので、φ_i の変化は e_i − Δmax で、どちらも [min(0, h), max(0, h)]/T に入り、|Δφ_i| ≤ |h|/T。よって **Min-p はマージン ＞ |h|/T で集合が変わらない**（PROJECT_A `MARGIN_STABILITY.md` の片側の揺れの形、osc ＝ |h|/T）。割る型も、見たことのあるトークンの logit は 0 に近づく向きにしか動かないので、同じく片側の幅で読める。
