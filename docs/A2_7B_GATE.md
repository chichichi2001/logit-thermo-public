## 1. 腕（モデルごとに 8 本）

- **なし**：禁止しない。
- **なし（別の種）**：禁止しない。生成の種だけ変える。種のぶれ（床）をこの実験の中で測る。
- **写しの禁止（小数の濃さ）**：3 トークンの写し（直前の 2 トークンがそれまでの文に出ていて、そのとき続いたトークン）を、各歩・各記事で確率 q で禁止する（その歩の候補を全部。logit を −∞）。q ＝ 1/3・2/3・1（q ＝ 1 は A2-7 の n ＝ 3 と同じ禁止）。
- **偽薬（濃さ 3 段）**：その歩の 1 位のトークンが 3 トークンの写しの候補でないときだけ、1 位を禁止する。禁止する歩の割合（全部の歩 × 記事のうち）を r ＝ 0.025・0.05・0.075 にする（A2-4 の偽薬と同じ「残りの借り」の配り方）。
- 量の目安（探索 8.11 の数から。1 回の禁止で取り上げる確率は、写し 0.83〜0.85、偽薬 0.54〜0.59）：写しの禁止は量 0.01〜0.04、偽薬は 0.014・0.029・0.043 くらいになるはず。偽薬の濃さは、写しの禁止の 3 本と量がだいたい重なるように選んだ（線が曲がっていても、同じ量の範囲で傾きを比べるため）。

- モデル：Pythia-1B・OLMo-2-1B・Qwen2.5-1.5B（A2-4・A2-7 と同じ）。float32（行列積は highest）、L4。ノートブックはモデルごとに 1 本（3 枠で並べて回す）。
- 記事・書き出し・512 歩：A2-2 と同じ（40 本、書き出し 64 トークン）。サンプル 2。
- 温度：0.4・0.5・0.6・0.7・0.8・0.85・0.9・1.0 の 8 つ（A2-7 より下に 0.2 広げた）。
- 生成の種：SEED7B ＝ 20261110。温度の番号 k（上の 8 つでの順番）とサンプル s で SEED7B ＋ 1000 × k ＋ s。8 本の腕で同じ種（「なし（別の種）」だけ ＋ 500000）。禁止のくじ（q と r）は、別の乱数（SEED7B ＋ 900000 ＋ 1000 × k ＋ s）で引く。
- 人の続きでの ℓ（teacher forcing）：この 8 つの温度で、モデルごとに 1 回出す。
- T_0：A2-4 と同じ（記事ごとの f の中央値に PAV、交点）。ε はモデルごとに 1 つ：「なし」の 8 つの温度のデータで出す。
- 量（mass）：禁止したトークンの、その温度の分布（禁止の前）での確率の合計を、全歩・全サンプル・全記事で平均し、温度 0.8・0.85・0.9 で平均したもの（探索 8.11 と同じ）。「なし」は 0。
- 下がり方 y ＝ log(T_0(腕) ÷ T_0(なし))。

## 3. 問いと決め方

- **BQ1（写しの禁止のほうが、同じ量でよく効くモデルの数、0〜3）**：モデルごとに、写しの禁止の 3 本と偽薬の 3 本それぞれで、原点を通る直線 y ＝ −K × 量 を最小二乗で当てはめる（交点が出た腕だけ。どちらかで 2 本未満なら「はっきりしない」）。比 Q ＝ K_写し ÷ K_偽薬。
  - 記事を選び直すブートストラップ（1,000 回、種 20261111。8 本の腕で同じ選び方、量もその選び直しで出し直す）で log Q の 95% 区間を出す（K_偽薬 ≤ 0 < K_写し の回は log Q ＝ ＋∞、逆は −∞、両方 ≤ 0 は数えない。区間は内挿しない分位点）。選び直しの 1 割を超える回で、点のとき使った腕のどれかの交点が出なければ「はっきりしない」。
  - 「写しの禁止のほうがよく効く」：区間の下 > 0、かつ点の Q ≥ 1.5
  - 「同じくらい（束一的）」：区間が log(1/1.5)〜log(1.5) に収まる
  - 「偽薬のほうがよく効く」：区間の上 < 0、かつ点の Q ≤ 1/1.5
  - それ以外は「はっきりしない」
  - BQ1 の答え ＝ 「写しの禁止のほうがよく効く」になったモデルの数。
- **BQ2（偽薬だけでも融点がはっきり下がるモデルの数、0〜3）**：偽薬 r ＝ 0.075（いちばん濃い偽薬）と「なし」を、A2-4 と同じ組のブートストラップ（paired、2,000 回、種 1）と同じ言葉（verdict_inf）で比べる。「大きく下がる」「大きく下がる（格子の外）」「少し下がる」のどれかになったモデルの数。

## 6. 承知している弱いところ

- **線がまっすぐとは限らない**：探索 8.11 では、Qwen の写しの禁止は濃くするほど効きが鈍った（上に凸）。原点を通る直線の傾きは、量の範囲で変わりうる。偽薬の濃さを写しの禁止と同じ量の範囲（〜0.04）にそろえたのはそのため。それでも実際の量がずれたら、線が上に凸のとき「量の範囲が広いほうの K が小さめに出る」向きのずれが残る（記録の量で確かめる）。
- **種の床は 1 組だけ**：「なし（別の種）」は 1 本なので、種のぶれの大きさは粗くしか分からない。BQ1 のブートストラップには記事のぶれしか入っていない。
- 偽薬は「1 位を禁止する」なので、写しの禁止とは取り上げるトークンの種類（自信の強さ）も違う。量はそろえられても、「どのトークンか」はそろわない。そこが問いそのものでもある。
- 温度 0.4・0.5 はほとんど貪欲なので、交点がそこに来たときの T_0 は粗い。
