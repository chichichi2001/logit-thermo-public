## 3. 読み方（記録と後知恵）

- **T_0 は丈夫な物差し**：種だけの床（組）は 1〜2%。判定に使った床（4.5%）を決めたのは「記事を 20 本ずつに分けた」床で、40 本のうちどの記事を使うかで T_0 が 4〜5% 動く、ということ。家族の差（最大 13%）は、種の床の 7 倍、記事の床の 3 倍。A2-6 の Q8 は記事を選び直すブートストラップで判定しているので、記事の床はすでに区間に入っている。
- **傾き s はほとんど使えない**：同じ Qwen2.5-1.5B を種だけ変えて回すと、s が 11.1 と 5.5 になった。2 点の差で取った傾きは、床が家族の差と同じくらい大きい。A2-6 の結果ノートの「Qwen は鋭く溶ける（s が大きい）」と、それから出した ΔH の見積もりの家族の差（Qwen3 で 10〜15、Pythia で 3 前後）は、**床と見分けられない**。Qwen3 の s（11.5〜16.4）だけが床（11.2）をわずかに上回る。
- **G07 は種にとても弱い**：SmolLM2-1.7B では種を変えただけで 0.51 → 0.68。Pythia の床は小さい（組で 0.039）が、決まりどおり 4 組の最大を床にしたので、A2-5 の「学ぶほどガラス寄り」の差（端から端で 0.13）は床の中になった。A2-5 の Q2 の判定（ρ ＝ 1、記事のブートストラップで 98%）は変えないが、そのブートストラップには種のぶれが入っていない。「学ぶほどガラス寄り」は、種のぶれまで入れると言い切れない。
- **F07 の床 0.95 ナット**：Pythia の大きさによる深さの違い（−2.22 → −0.55、差 1.7）は床を超える。家族どうしの F07 の差の多くは床の近く。
