# A2-6F のゲート：しらふ同士の床と、家族の差の天井 v1.0（凍結 2026-10-29 13:0x JST）

## 1. 床の材料（3 種類。どれも GPU を使わない）

**(a) 組の床**：同じモデル・同じ 40 本の記事・同じコードで、生成の種だけ違う 2 回。

| モデル | 古い種（20261027） | 新しい種（20261102） |
|---|---|---|
| Pythia-1B | A2-2 | A2-5 |
| Qwen2.5-0.5B | A2-2 | A2-6 |
| Qwen2.5-1.5B | A2-2 | A2-6 |
| SmolLM2-1.7B | A2-2 | A2-6 |

**(b) 種の半分の床**（オーナーの（オーナーの承認・発言。原文は非公開の記録にある）を受けて足した）：どの回も、記事ごと・温度ごとに 2 本ずつ生成している。1 本目だけ・2 本目だけで測った 2 つの差。A2-2 の 7 回、A2-5 の 9 回、A2-6 の 9 回の全部（25 組）。

**(c) 記事の半分の床**：使った記事を、並びの偶数番目と奇数番目の 20 本ずつに分けて測った差。25 組。G07 は「30 本以上で読む」決まりなので出さない（T_0・F07・s だけ）。

- 半分どうしの差は、1 回まるごとどうしの差より、およそ √2 倍大きく出る（半分は雑音の分散が 2 倍になるため）。そこで (b)・(c) は **95% 点を √2 で割った値**を、(a) の床とくらべる。
- 「人工の雑音を足して床を作る」のはやらない：足した雑音の大きさを自分で決めることになり、しらふ同士の差（本物の床）にならないため。

## 2. 測る量（どれも、これまでの実験と同じ出し方）

- T_0（モデルごとの ε、A2-2 のとおり）。差は |log(T_0 の比)|。
- F07（温度 0.7 での F、ナット）。差は絶対値。
- s（A2-5b の傾き、ナット ÷ 温度 1）。差は絶対値。
- G07（温度 0.7、128〜512 トークン目のガラスの割合、A2-5 のとおり）。差は絶対値。
- **判定に使う床 ＝ 「(a) の 4 組の差のいちばん大きい値」と「(b)・(c) の差の 95% 点 ÷ √2」のうち、いちばん大きい値**（量ごとに）。(a) の中央値、(b)・(c) の 95% 点・いちばん大きい値・交点が出た数も記録する。
- 半分では交点が出ない（T_0 がない）ことがある。そのときはその組を外し、外した数を記録する。

## 3. 判定（決まりだけ固定する）

- **F1**：T_0 の床（比に戻した値）が 1.05 より小さい →「床は 5% の線の内側」（A2-6 の Q9「動かない」の線が床より上にある）。そうでなければ「床が 5% の線に届く」（Q9 の「動かない」は床と見分けられない）。
- **F2**：A2-6 の家族ごとの T_0 の幾何平均のうち、いちばん離れた 2 家族の |log 比|（天井）が、T_0 の床の 3 倍以上 →「天井は床の 3 倍以上」。そうでなければ「天井は床の 3 倍より小さい」。A2-6 の要約がなければ「読めない」。
- **F3**：A2-5 の学びの軸（step 8000 → 24000 → 64000 → 143000）の隣どうしの G07 の差が、G07 の床を超える数（0〜3）。あわせて、端から端（8000 → 143000）の差が床を超えるかも書く。

## 4. 使い方

- A2-6 の結果ノートでは、F1・F2 を並べて書く。F1 が「床が 5% の線に届く」なら、Q9 の「動かない」は「床と見分けられない」と書き添える。
- A2-5 の結果ノートに、F3 を追記する（Q2 の判定は変えない。「一歩ずつ上がる」と言えるかどうかの注として）。

## 5. 承知している弱いところ

- (a) は 4 組だけ。(b)・(c) で 25 組ずつ足したが、半分のデータから 1 回分の床に直す「√2 で割る」は、雑音が記事どうし・サンプルどうしで独立という仮定に立っている。
- (b)・(c) の 25 組には同じモデルの回が重なっている（例：Pythia-1B は A2-2 と A2-5 の両方）。25 組はおたがいに独立ではない。
- 記事の床は「同じ 40 本の中の分け方」で測る。まったく別の記事の組に入れ替えたときの床は測らない（GPU が要る。必要なら別に）。
- Pythia-1B の組は A2-5 の Q2 のデータと重なっている（step 143000 ＝ 学習の終わりの新しい種）。
