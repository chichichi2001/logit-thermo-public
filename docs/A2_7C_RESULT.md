## 3. 読み

- **向きは Pythia・OLMo と同じ**：写しの禁止は量に沿ってまっすぐ T_0 を下げ（−0.11 → −0.15 → −0.21）、偽薬は同じ量で −0.03〜−0.07 にとどまった。Q は Pythia 29、OLMo 4.9、Qwen 2.9。3 モデルとも「不凍たんぱく質」寄りの並びだが、Qwen は判定の決まりを満たさなかった。
- **Qwen の偽薬は、ほかの 2 モデルより少しだけ効いている**ように見える（−0.03〜−0.07。Pythia −0.005、OLMo −0.03）。ただし種の床（なし（別の種））が −0.013 [−0.054, ＋0.069] で、区間はどれも 0 をまたぐ。「塩の分が少しある」と言える強さではない。
