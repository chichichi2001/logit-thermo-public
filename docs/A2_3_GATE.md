## 1. 問い

A2-2 では、生成のフィードバックが向きを変える温度 T_0 が、4 家族・7 モデル（素と指示調整、0.5B〜1.7B）で **0.80〜0.91** に収まった。一歩の平衡の量（温度計 T_cal、裾の傾き a、一歩の状態）はどれもこのばらつきを当てられず、「ほかの家族の平均」がいちばん良かった。

> T_0 がほぼ一定なのは、この大きさ・この文章（BBC のニュース）だけの話か、もっと一般的か。

**この予言は A2-2 の数字を見てから作った**。だから、確かめるのは**新しいモデル・文章の組**だけ（§3）。A2-2 の組は使わない（A100 の確かめを除く）。

## 2. 予言と判定

- **帯**：T_0 ∈ **[0.78, 0.93]**（中心 約 0.852、幅 約 ±9%）。A2-2 の 7 モデルの最小 0.800・最大 0.910 から、両側に約 2.5% 広げたもの。A2-2 の結果を見たあと、新しい条件のデータを見る前（2026-10-28 12:1x）に `A2_2_RESULT.md` §6 に書いた帯のまま。
- **T_0 の求め方**：A2-2 と同じ（`scripts/a2_2_analyze.py` の `pav`・`crossing_mono`・`feedback_stats`・`per_doc_feedback` を**変えずに**使う）。F(T) を単調に当てはめ、−ε 以下から +ε 以上へ移る温度。ε はデータのばらつきから決める。95% 区間は書き出し単位のブートストラップ 2,000 回。

### 条件ごとの判定
- **帯に入る**：T_0 が帯の中、かつ 95% 区間の上 ÷ 下 ≤ 1.20、かつブートストラップで交差のある回の割合 ≥ 0.9。（A2-2 では区間の上 ÷ 下は 1.07〜1.11、交差のある回の割合は全モデル 1.0。）
- **帯の外**：次のどちらか。
  - T_0 が帯の外で、かつ 95% 区間が帯と重ならない。
  - 交差がなく、単調に当てはめた F が T = 0.6 ですでに +ε 以上（T_0 < 0.6）、または T = 1.5 でまだ −ε 以下（T_0 > 1.5）。
- **はっきりしない**：上のどちらでもないもの。具体的には、T_0 は帯の外だが区間が帯にかかる。T_0 は帯の中だが区間の上 ÷ 下が 1.20 を超える。交差のある回の割合が 0.9 未満。区間が出ない。交差がなく、当てはめた F が ±ε の中にとどまる（「見かけ」の形）。

### 全体の判定
- 5 つの条件（§3）が全部「帯に入る」→ **一般的**。
- 1 つでも「帯の外」→ **一般的ではない**。
- それ以外 → **はっきりしない**。
- **A100 の確かめ**（§4）が通らなければ、全体を「はっきりしない」にする。

### 参考の判定（点の値だけ。v0.2 の追記、オーナーの予想のあと・凍結の前、14:08 のオーナーの選択）
本命の判定は端で「はっきりしない」に落ちやすい（区間の半分の幅が約 4〜5%、帯の半分の幅が約 9%）。どちらに傾いているかを必ず残すため、点の値だけで決める参考の判定を足す。**結論は本命の判定で書き、参考の判定は「傾き」として添える。**
- 条件ごと：T_0 の点が帯の中なら「帯に入る」、帯の下なら「帯の外（下）」、上なら「帯の外（上）」。交差がない場合は、当てはめた F が T = 0.6 ですでに +ε 以上なら「帯の外（下）」、T = 1.5 でまだ −ε 以下なら「帯の外（上）」、F が ±ε の中にとどまるなら、当てはめた F の絶対値がいちばん小さい温度を点とみなす。
- 全体：5 つの点が全部帯の中なら「一般的」、そうでなければ「一般的ではない」。
- A100 の確かめが通らなかったときも、参考の判定は書く（そのことを添えて）。

### 軸ごとの読み方（先に決める）
- **大きさ**：「大きさによる」と書けるのは、7B が 2 つとも同じ向きに帯の外へ出たときだけ。片方だけなら「その家族では外れる」まで。Qwen は 0.5B・1.5B・7B が同じ学習データの並びなので比べとしてきれい。OLMo-2-1124-7B と OLMo-2-0425-1B は出た時期も学習データの混ぜ方も違うので、大きさだけの比べにはならない。大きさの軸は「同じ 40 本の BBC の上での比べ」。
- **文章**：3 つとも同じ向きに帯の外 → 「文章の種類による」。1 つだけ → 「モデルと文章の組み合わせによる」。

### 「一般的」になっても言えること・言えないこと
- 言えるのは「T_0 は A2-2 の幅（0.852 を中心に約 ±9%）を超えない」まで。範囲は、素のモデル・英語・7.6B まで・ニュースとコード。
- 言えないこと：ほかの言語、会話、7B の指示調整版、もっと大きいモデル。「T_0 ≈ 0.85 で普遍的」とは言わない。

## 4. A100 の確かめ（罠）

7B は A2-2 の GPU（L4）とは別の GPU（A100）で回す。数字の丸めの違いを確かめるため、**Qwen2.5-1.5B の BBC を A100 でもう一度回す**（記事も種も A2-2 と同じ）。
- (a) 人の文脈の数字（ℓ_tf の全要素、T_cal）が A2-2 の値とほぼ一致する：ℓ_tf の最大の差 ≤ 1e-3、T_cal の差 ≤ 1e-3。
- (b) T_0 の差：記事を組にしたブートストラップで log（A100 の T_0 ÷ A2-2 の T_0）の 95% 区間が 0 を含む、または |log 比| ≤ 0.03。
- (a) と (b) の両方が通れば OK。どちらかが外れたら、全体を「はっきりしない」にする。
