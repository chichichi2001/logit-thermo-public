## 3. 読み

- **偽薬は本当の融点をはっきり下げる**：3 モデルとも、濃くするほど順に下がり、30% で 10〜20%。種の床（±0.03）を大きく越える。
- **線は曲がる（理想からずれる）**：濃さ 1 あたりの下がり方（−y_m ÷ 濃さ）は、7.5%・15%・30% で Pythia 0.54・0.46・0.34、OLMo 0.94・0.92・0.65、Qwen 1.05・0.99・0.73。OLMo と Qwen は 15% まではほぼまっすぐで、30% で鈍る。Pythia は最初から鈍っていく。取り上げた確率の量あたりでも同じ形（30% で鈍る）。理想の凝固点降下より下がり方が小さい側のずれ。
- **T_0 も下がった**：A2-7b・A2-7c では偽薬 7.5% で T_0 はほとんど動かなかったが（Pythia −0.005、OLMo −0.029、Qwen −0.069）、今回は Pythia −0.040、OLMo −0.094、Qwen −0.011。一方 T_m の下がり方は、探索 8.16（A2-7b の生成から）と今回でよく合う（7.5% で Pythia −0.055 と −0.040、OLMo −0.058 と −0.071、Qwen −0.082 と −0.078）。T_0 の下がり方は、温度の格子と ε の出し方で変わりやすく、T_m のほうが安定した物差しだった。探索 8.16 の「T_m のほうが T_0 より速く下がる」は、A2-7b の T_0（ε がふくらんでいた格子）と比べたもので、今回の格子では Pythia・OLMo で成り立たなかった（Qwen は点では成り立つが区間が 0 をまたぐ）。
- **ファントホッフの ΔH も塩で下がる**：Pythia 3.87 → 2.83、OLMo 3.28 → 2.67、Qwen 3.06 → 2.39（濃さに沿って、だんだん鈍る）。
