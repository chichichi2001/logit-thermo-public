## 1. 問い

探索（同じデータの見直し）で、次のことが見えた。
- 温度が低いと、書き始めは自分の文脈のほうが「温まる」（裾が太い）のに、書き進めると「冷えて固まる」（裾が細る）。T_0 は、その固まりが 512 トークンのうちに始まる温度に近い。
- 固まり方は 2 つが混ざっている。**結晶**（それまでの 4 トークンの並びをそのまま写す歩）と、**ガラス**（写していないのに自信が固まる歩）。T_0 に近いほどガラスの割合が上がり、冷やすほど結晶が育つ向き（9 モデル中 6 つ）。

> 4 トークンの完全な写し（結晶）だけを止めると、T_0 は動くか。

## 2. つまみ

- **λ ＝ 0**：つまみなし。
- **λ ＝ ∞（写しの禁止）**：各歩で、直前の 3 トークン（a, b, c）がそれまでの文（書き出しを含む）に出ていたら、そのとき続いたトークン d（a b c d がすでにある d）を禁止する（logit を −∞ にする）。Hugging Face の no_repeat_ngram_size ＝ 4 と同じ。写し歩（探索 C の定義）は作りからして 0 になる。
- **偽薬**：λ ＝ ∞ の生成で、「禁止したトークンが、つまみをかける前の 1 位だった歩」の割合を、モデル・温度ごとに数える（p(T)）。偽薬の生成では、**写しかけ歩（禁止の候補がある歩）でない歩**から、確率 p(T) でランダムに歩を選び、その歩のつまみ前の 1 位を禁止する。λ ＝ ∞ は「写し歩がなくなる」と「確率の高いトークンを取り上げて選び直させる」が同時に起きるので、2 つ目だけを真似る対照。
  - 偽薬の歩の選び方の乱数は、生成の乱数と別の種で決める。
- 3 つとも、温度で割る前の logit にかける。

## 3. 物差しと記録（一歩の恒等式の罠を避ける）

- **本命の物差し**：つまみをかける前の logit で計算した ℓ（H ＝ 100）。生成の文脈では ℓ_gen,raw（つまみをかけて生成した文脈で、その歩のつまみ前の logit から計算）。人の文脈では ℓ_tf（A2-2 と同じ。つまみはかからない）。f_raw ＝ ℓ_gen,raw − ℓ_tf。つまみが f_raw に効くのは「どんな文脈が書かれるか」を通してだけになる。
- **歩ごとの印**（すべての λ と偽薬で記録）：
  - 写しかけ歩か（禁止の候補が 1 つ以上あるか）。λ ＝ 0 でも同じ規則で印をつける。
  - 禁止の候補の、つまみ前の確率の合計。
  - その歩で実際に禁止した（偽薬では、1 位を禁止した）か。
- **結晶とガラスの分け方**は、写し歩ではなく**写しかけ歩**の印で行う（λ ＝ ∞ では写し歩が 0 なので、写し歩で分けると止められた写しが全部ガラスに数えられてしまうため）。

## 4. 条件

- モデル（L4、fp32）：**Pythia-1B、OLMo-2-0425-1B、Qwen2.5-1.5B**。
- 文章・書き出し・温度の格子・長さ：A2-2 と同じ（BBC の 40 本、書き出し 64 トークン、続き 512 トークン、温度 15 点、2 本ずつ）。

- 見込み：L4 で 1 回 20〜30 分、合計 3〜5 時間（約 5〜9 CU）。

## 5. 予言と判定（データを見る前に決める）

T_0 の求め方は A2-2 と同じ（`pav`・`crossing_mono`・`per_doc_feedback` を変えずに使う）。ただし f は §3 の f_raw で、**ε はモデルごとに 1 つに固定する**：λ ＝ 0 の全データで `feedback_stats` が出す ε を、そのモデルの λ ＝ ∞ と偽薬にも使い、ブートストラップの中でも同じ ε を使う（ε が条件ごとに変わると、それだけで T_0 が数 % 動くため。A2-3 の Qwen2.5-7B では ε を替えただけで 0.930 → 0.857）。

### 動きの大きさ
- d_∞ ＝ log（T_0(λ＝∞) ÷ T_0(λ＝0)）、d_偽 ＝ log（T_0(偽薬) ÷ T_0(λ＝0)）、d_差 ＝ d_∞ − d_偽。
- 95% 区間は、記事の番号を共有したブートストラップ 2,000 回（種 1）。各回で、比べる両方が交差した回だけを使う。その割合が 0.9 未満なら、その d は「はっきりしない」。

### モデルごとの判定（d_∞）
- **大きく下がる**：区間の上の端 < 0、かつ点 ≤ −0.10。
- **少し下がる**：区間の上の端 < 0、かつ点 > −0.10。
- **上がる**：区間の下の端 > 0。
- **10% 以上は動かない**：区間が [−0.10, +0.10] の中に収まり、0 を含む。
- **はっきりしない**：上のどれでもない。
- 交差がなくなった場合：単調に当てはめた F が T ＝ 0.6 ですでに +ε 以上なら「大きく下がる（格子の外）」、T ＝ 1.5 でまだ −ε 以下なら「上がる（格子の外）」、それ以外は「はっきりしない」。
- 10% の線について：A2-3 の A100 の確かめでは、同じ条件のやり直しでも log 比の区間が −0.04〜+0.08 だった。40 本の記事では、これより細かい「動かない」は言えない。だから「10% 以上は動かない」は「効き目がない」という意味ではない。

### モデルごとの判定（偽薬との差 d_差）
- **写しを止めた分がある**：d_差 の区間の上の端 < 0（写しの禁止のほうが、偽薬より T_0 を下げた）。
- **偽薬と区別できない**：区間が 0 を含む。
- **偽薬のほうが下げた**：区間の下の端 > 0。

### 全体の問い（QB1）
- 3 モデルとも「写しを止めた分がある」→ **「4 トークンの完全な写しは T_0 を支えている」**。
- 3 モデルとも「偽薬と区別できない」かつ d_∞ が「10% 以上は動かない」→ **「T_0 は 4 トークンの完全な写しでは決まっていない」**。
- 上の 2 つの両方の型のモデルが 1 つ以上ずつある → **「モデルによる」**。
- それ以外 → **「はっきりしない」**。
- どの結論も、範囲は「4 トークンの完全な写し」に限る（3 トークンの写し、言い換え、分かち書きを変えた写しは止めていない）。

### 物差しとしての見積もり（記録。判定しない）
- **機械的な見積もり d_機**：新しい λ ＝ 0 の生成で、記事ごとに f_raw から「結晶の分」（写しかけ歩の印で分けたもの）を引き、同じ ε で T_0 を出し直して、log（T_0（結晶を引いた）÷ T_0(λ＝0)）。フィードバックが何もしなければ、写しを止めたときの動きはだいたいこれくらい、という目安。
- 読み方：r ＝ d_差 ÷ d_機（点の値）。r > 1.5 なら「フィードバックで増えた」、0.67〜1.5 なら「ほぼ見積もりどおり」、0〜0.67 なら「打ち消された」（千紗の言っていたルシャトリエの原理の向き）、r < 0 なら「逆向き」。d_機 の絶対値が 0.01 より小さいときは読まない。
- 3 モデルの d_差 の並びと d_機 の並びが同じか（記録）。v0.1 の「結晶の割合で並べる」は、F を動かすのが割合ではなく結晶の分の大きさなので、やめた（既存のデータでの素朴な見積もりでは、並びは v0.1 の予想と逆になる）。

## 6. 確かめ（罠）

1. **λ ＝ 0 が A2-2 と同じ測り方になっている**：人の文脈の ℓ_tf の最大の差 ≤ 1e-3。T_0 の log 比（新しい種 ÷ A2-2）の点が ±0.05 以内（種が違うので生成は一致しない。A2-3 の A100 の確かめでは、生成が違っても −0.004 だった）。通らなければ全体を「はっきりしない」にする。
2. **つまみ前の logit を記録している**：禁止の候補があった歩で、記録した ℓ が、つまみ前の logit から計算し直した値と一致し（相対 1e-6）、つまみ後の logit から計算した値とは違うこと。
3. **λ ＝ ∞ で写し歩が 0**（つまみの作りの確かめ）。
4. **偽薬の禁止の割合が狙いどおり**：偽薬で 1 位を禁止した歩の割合が、温度ごとに p(T) の ±20%（相対）以内。
5. 生成の 1 歩目は、λ ＝ 0・∞・偽薬で同じ分布（1 歩目に禁止の候補がない記事で）。
