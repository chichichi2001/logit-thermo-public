## 3. 読み

- **同じ量を取り上げても、写しの禁止は融点を 10〜29% 下げ、偽薬は「別の種で回しただけ」と同じくらいしか動かさない**。偽薬の y（−0.065〜＋0.007）は、この実験の中の種の床（なし（別の種）：＋0.022、−0.046）と同じ大きさ。写しの禁止の y は、いちばん薄い q ＝ 1/3 でも床の 2.5〜9 倍。
- 探索 8.11 の下見（偽薬 1 点、差は床と同じくらい）で言い切れなかった「写しの禁止は特別」が、Pythia と OLMo でははっきり出た。量で効く「塩」（束一的）ではなく、結晶の育つところだけをふさぐ「不凍たんぱく質」型。
- BQ2 ＝ 0：1 位のトークンを全部の歩の 7.5% で取り上げても、融点は 10% も動かない。この範囲の量では、「塩」の効き目はほぼ見えない。

## 4. Qwen が判定できなかった理由（設計の失敗）

- ε（「F が 0 と区別できない幅」）は、「なし」の 8 つの温度で、記事を選び直したときの F の区間の半分の幅の**中央値**として出す（A2-4 と同じ決め方）。
- 格子を 0.4・0.5 まで下げたことで、F が大きく負でばらつきも大きい温度が 2 つ増え、中央値が上がった。ε は A2-7（温度 0.6〜1.05）と比べて Pythia 0.16 → 0.28、OLMo 0.17 → 0.32、Qwen 0.51 → **0.87**。
- Qwen の「なし」の F は 0.9 で −0.00、1.0 で ＋0.75 で、＋ε（0.87）に届く温度がない。なので交点が出ず（平ら）、Qwen は全部の腕が判定できなくなった。Pythia の q ＝ 1 も同じ理由で平ら。
- **後知恵**：A2-7 の後知恵どおり格子を下に広げたが、その結果 ε がふくらむことを見落としていた。格子の上側（1.05〜1.1）も残すべきだった。また ε を「T_0 のまわりの温度だけ」で出す決め方にしておけば避けられた。判定は変えない。
- 記録（判定しない）：Qwen の F の並びは、ほかの 2 モデルと同じ向き。温度 0.4 での F は、なし −12.3、偽薬 7.5% −10.6、写し q ＝ 1 −2.7。
