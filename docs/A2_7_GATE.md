## 1. 濃さ（禁止する写しの長さ n）

- n トークンの完全な写し（直前の n − 1 トークンがそれまでの文に出ていて、そのとき続いたトークン）を禁止する（logit を −∞。no_repeat_ngram_size ＝ n）。n が小さいほど濃い。
- 並び（薄い → 濃い）：なし・n ＝ 8・6・4・3・2。**なし と n ＝ 4 は A2-4 のデータをそのまま使う**（同じ記事、同じ生成の種、同じコード）。n ＝ 8・6・3・2 を新しく回す。
- n ＝ 4 の新しいコードが A2-4 の block と同じトークンを出すことを、自己テストで確かめる。

## 2. 手順

- モデル：Pythia-1B・OLMo-2-1B・Qwen2.5-1.5B（A2-4 と同じ）。float32、L4。
- 温度：T_0 のまわりの 8 つ（0.6・0.7・0.8・0.85・0.9・0.95・1.0・1.05）。A2-4 の「なし」「n ＝ 4」もこの 8 つだけを使う。
- 生成の種：A2-4 と同じ（SEED4 ＋ 1000 × k ＋ s。k は 15 の温度での番号）。
- T_0：A2-4 と同じ（記事ごとの f の中央値に PAV、交点）。ε はモデルごとに 1 つ：「なし」の 8 つの温度のデータで出す。
- d ＝ log(T_0(n) ÷ T_0(なし))、記事を組にしたブートストラップ（2,000 回、種 1。A2-4 と同じ）。

## 3. 問いと決め方

- **TQ1（いちばん濃い n ＝ 2 で、OLMo と Qwen の T_0 はどうなるか）**：モデルごとに、A2-4 と同じ言葉で判定する。
  - 「大きく下がる」：区間の上 < 0、かつ点 ≤ −0.10（全部の温度で交点より上なら「大きく下がる（格子の外）」で、採点では同じ扱い）
  - 「少し下がる」：区間の上 < 0、かつ点 > −0.10
  - 「10% 以上は動かない」：区間が 0 をまたぎ、−0.10〜+0.10 に収まる
  - 「上がる」：区間の下 > 0
  - それ以外は「はっきりしない」
  - OLMo と Qwen をそれぞれ採点する。Pythia の n ＝ 2 は記録だけ。
- **TQ2（濃さに沿って T_0 がなめらかに下がるモデルの数、0〜3）**：モデルごとに、6 つの濃さ（なし・8・6・4・3・2）の順番と T_0 のスピアマン ρ ≤ −0.9、かつ記事を選び直すブートストラップ（1,000 回、種 20261107、6 つの濃さで同じ選び方）で ρ < 0 が 95% 以上 →「濃いほど下がる」。交点が全部の温度より下のときは T_0 ＝ 0.6（格子の下の端）として並べる。ブートストラップで並べられない回が 1 割を超えたら「はっきりしない」。

## 6. 承知している弱いところ

- **偽薬はない**：濃い禁止は、写しだけでなく 1 位のトークンも大量に取り上げる。T_0 が動いても「写しを止めたから」とは言えず、「強く邪魔したから」までしか言えない。TQ1 は「緩衝が破れるほど強く邪魔すれば動くか」を見る問い。
- トークンの並びでの禁止なので、別の区切り方で同じ文字列を書くすり抜けはありうる（A2-4 §4）。
- 温度を 8 つに減らしたので、T_0 の出し方は A2-4 と少し違う（ε も 8 つの温度で出す）。「なし」の T_0 は A2-4 の値と少しずれうる。
- n ＝ 8・6 は、もともと 8・6 トークンの写しが少ないので「なし」とほとんど変わらないかもしれない。
