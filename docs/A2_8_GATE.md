## 3. 問いと決め方

- **ファントホッフの当てはめ**：使う温度で ln K ＝ ΔH_vH × (1/T) − ΔS_vH を重みつき最小二乗で当てはめる（重み ＝ 1 ÷ (1/凍る回 ＋ 1/溶ける回)）。T_m ＝ ΔH_vH ÷ ΔS_vH（ΔH_vH > 0 かつ ΔS_vH > 0 のときだけ）。単位：ΔH はナット（1 回の相転移あたり）、T は温度（単位なし）。使う温度が 3 つ未満なら「はっきりしない」。
- **熱量計の ΔH**：使う温度それぞれで「液体の歩の U の平均 − 結晶の歩の U の平均」（ナット／トークン）を出し、使う温度で平均する。
- 記事を選び直すブートストラップ（1,000 回、種 20261112。使う温度は点のときと同じ）で、ΔH_vH・T_m・熱量計の ΔH・n の 95% 区間（内挿しない分位点）。選び直しで当てはめが成り立たない回が 1 割を超えたら Q1 は「はっきりしない」。
- **Q1（T_m が T_0 と合うモデルの数、0〜3）**：T_0 のものさしは A2-2 の結果（Pythia 0.852 [0.810, 0.869]、OLMo 0.801 [0.776, 0.856]、Qwen 0.910 [0.862, 0.957]）。モデルごとに：
  - 「合う」：T_m の区間が T_0 の区間と重なり、かつ T_m の区間が T_0 ÷ 1.1 〜 T_0 × 1.1 に収まる
  - 「ずれる（高い）」：T_m の区間の下が T_0 の区間の上より上
  - 「ずれる（低い）」：T_m の区間の上が T_0 の区間の下より下
  - それ以外は「はっきりしない」
  - Q1 の答え ＝ 「合う」のモデルの数。
- **Q2（協同性の単位 n の言葉）**：n ＝ ΔH_vH ÷ 熱量計の ΔH（点）。n が出た 2 モデル以上の中央値で言葉を決める（2 モデル未満なら「はっきりしない」）：
  - 「1 より小さい（途中の段がある）」：n < 0.5
  - 「1 くらい（ばらばらに溶ける）」：0.5 ≤ n < 2
  - 「数トークン（2〜10）」：2 ≤ n < 10
  - 「数十トークン（10〜100、結晶核くらい）」：10 ≤ n < 100
  - 「100 トークン以上」：n ≥ 100
  - 「向きが逆」：n ≤ 0

## 6. 承知している弱いところ

- **作り物での偏り**：決めた速さで行き来する作り物（ΔH ＝ 6、T_m ＝ 0.8、液体 3.2・結晶 0.2 ナット）で確かめたところ、ΔH_vH は 6.8（1 割強大きい）、T_m は 0.816（2% 高い）、熱量計の ΔH は 2.46（2 割弱小さい。相の境目の歩が混ざるため）で、n は 2.75（本当は 2、1.4 倍くらい）に出た。Q1 の幅（1.1 倍）と Q2 の段（3〜10 倍）はこれより粗いが、境目の近くでは段を 1 つ上に読むことがある。区間は記事のぶれだけで、この偏りは入っていない。
- **平衡かどうか**：結晶がほとんど溶けない温度では K が出ない（使う温度から外れる）。行き来があっても、K が本当に「平衡」の量かは分からない。
- **2 つの状態とは限らない**：途中の段（短い繰り返し、半分だけの写しなど）があると、ln K の直線は曲がり、n は小さく出る（タンパク質で ΔH_vH ÷ ΔH_cal < 1 になるのと同じ）。
- **エネルギーの選び方**：熱量計の ΔH は温度 1 の −log p で測る。生成は 1 歩ずつ温度をかけるので、列全体の分布は p₁(列)^(1/T) と同じではない。n はその違いも含んだ数になる。
- **T_0 のものさしは同じ生成から**：A2-2 の T_0 も A2-2 の生成から出ている（ただし ℓ の交点で、写しの印は使っていない）。
- 写しの印は 4 トークンの繰り返しなので、周期が長い・形が崩れた結晶は液体に数えられる。
