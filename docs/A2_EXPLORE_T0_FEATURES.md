- **低めの温度（0.7）でも、書き始めは「温まる」（f がプラス、自分の文脈のほうが裾が太い）。** 書き進めると、どこかで「冷えて固まる」（f が大きくマイナス、自信が強くなって裾が細る）。
- 横切る温度は、位置が後ろになるほど上がり、128〜512 トークン目でようやく全体の T_0 とそろう。**32〜128 から 128〜512 でもまだ上がっている**ので、512 トークンで落ち着ききっていない可能性がある。
- 千紗の「結晶化」の見立て（核ができてから育つ、過冷却）と同じ形。読み方の候補：**T_0 は「512 トークンのあいだに固まりが始まる、いちばん高い温度」**。そうだとすると、T_0 は融点そのものではなく、**固まるまでの時間で決まる量（速度論の量）**で、生成の長さを変えると動くはず。

## 3. T_0 のばらつきは、低い温度の側（固まる側）で決まっている

ニュースの 9 つの組（A2-2 の 7 つ ＋ 7B の 2 つ）で、T_0 と F の端の値の順位相関：
- T_0 と F（T = 0.6）：−0.83（p ≈ 0.005）。**低い温度で強く固まるモデルほど、T_0 が高い。**
- T_0 と F（T = 1.5）：−0.27（p ≈ 0.49）。高い温度の側は T_0 と関係が見えない。
- ただし、F の曲線が下にずれれば横切る温度は上がるので、この相関の一部は曲線の形からして当然。9 組しかない。

## 4. ただし「固まる」は、言葉のくり返しとは限らない

- T_0 と、T = 0.6 の後半 128 トークンの distinct-4（4 語の並びのくり返しの少なさ）の順位相関は −0.28（p ≈ 0.46）。関係が見えない。
- T_0 での distinct-4 は、ニュースで 0.94〜0.99（くり返しはほぼない）、コードで 0.77〜0.78（くり返しが多い。ただしコードはもともとくり返しが多く、人の書いたコードの distinct-4 は測っていない）。
- なので、低い温度で「裾が細る」のは、同じ言葉のくり返し（結晶）だけでは説明できない。**くり返さないのに自信だけが固まる状態**、つまり千紗の言っていた**ガラス**に近いのかもしれない。

## 5. ここから立てられそうな説明の候補（2・3 はオーナーと一緒に）

- **候補 A（速度論）：T_0 は「固まるまでの時間」で決まる。** 予言の形：生成を長くすると T_0 は上がり、ある値（融点）に近づいて止まる。短くすると下がる。
- **候補 B（2 つ目のつまみ）：固まるのを邪魔すると T_0 は下がる。** 繰り返しのペナルティや、確率の高すぎる候補を抑えるつまみで、固まりにくくすれば、同じ長さでも横切る温度が下がるはず。どの向きにどれだけ動くかは、候補 A と組み合わせて決められるかもしれない。
- **候補 C（ガラス）：固まり方は、くり返し（結晶）より、自信の固まり（ガラス）が主。** 予言の形：T_0 の近くで、くり返しの量より、1 位の確率の上がり方のほうが先に変わる。
- どれも、確かめるには新しいデータ（長さを変えた生成、つまみを入れた生成）が要る。位置ごとの f は、A2-3 の要約には入れていなかったので、A2-3 の 6 条件でも見るなら、生のファイルから計算し直す（CPU で数分）。
