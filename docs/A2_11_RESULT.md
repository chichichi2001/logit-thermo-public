## 1. 判定

- **CQ1：ほぼ動かない（0.8〜1.25 倍）**（n(印 6) ÷ n(印 3) は 0.99・0.96・1.17）

## 2. (C) 印の大きさを変えた結果

| モデル | 印 | T_m | ΔH_vH（ナット） | 熱量計の ΔH（ナット／トークン） | n |
|---|---|---|---|---|---|
| Pythia-1B | 3 / 4 / 6 | 0.579 / 0.567 / 0.554 | 4.23 / 4.17 / 4.20 | 1.34 / 1.28 / 1.34 | 3.16 / 3.26 / 3.13 |
| OLMo-2-1B | 3 / 4 / 6 | 0.549 / 0.533 / 0.517 | 3.86 / 3.86 / 3.82 | 1.38 / 1.37 / 1.43 | 2.79 / 2.83 / 2.68 |
| Qwen2.5-1.5B | 3 / 4 / 6 | 0.577 / 0.565 / 0.555 | 3.29 / 3.40 / 3.42 | 1.55 / 1.41 / 1.37 | 2.12 / 2.42 / 2.49 |

- **n は印の大きさを映していなかった**：印を 3 から 6 に倍にしても、n は 2〜3 のまま（印 − 1 なら 2 → 5 になるはずだった）。ファントホッフの ΔH も熱量計の ΔH もほとんど動かない。協同性の単位 n ≈ 2〜3 トークンは、決め方の作り物ではない量として扱ってよさそう。
- **T_m は印に沿って少しずつ動く**：印 3 → 6 で 2〜3% ずつ下がる（印 3 はよくある言い回しも結晶に数えるので、結晶寄りに出る）。動き方は 3 モデルとも同じ向き・同じくらい。

## 3. (D) 25 本の T_m⁺（温度 0.6 以上だけで出した T_m）

| 系統 | T_m⁺（小 → 大） | T_m⁺ ÷ T_0 |
|---|---|---|
| Pythia（A2-5） | 70m 0.700、160m 0.662、410m 0.615、1b 0.590、1.4b 0.597、2.8b 0.560 | 0.83 → 0.68 |
| Pythia-1B の学習の途中（A2-5） | step 8000 0.640、24000 0.646、64000 0.628、最後 0.590 | 0.76・0.79・0.73・0.70 |
| Qwen2.5 | 0.5b 0.642・0.644、1.5b 0.611・0.606、3b 0.585（0.5b-inst 0.622） | 0.75〜0.76 → 0.64 |
| Qwen3 | 0.6b 0.667、1.7b 0.592、4b 0.612 | 0.75 → 0.64〜0.66 |
| SmolLM2 | 135m 0.614、360m 0.577、1.7b 0.559・0.528（1.7b-inst 0.548） | 0.76 → 0.66〜0.70 |
| OLMo-2-1B | 0.586 | 0.73 |

- **大きいモデルほど融点が下がる**：Pythia では 1 桁大きくなるごとに T_m⁺ が 0.084 下がる（70m → 2.8b で 0.70 → 0.56）。Qwen2.5・Qwen3・SmolLM2 でも、いちばん小さいものがいちばん高い。T_0 は大きさでほとんど動かない（Pythia で 0.82〜0.85）ので、比 T_m ÷ T_0 も大きいほど小さくなる。
- **学習が進むほど融点が下がる**（Pythia-1B、step 24000 以降）。
- **比は「ゆるくそろう」だが、ばらつきの多くは大きさの並び**：25 本の比は 0.64〜0.83。大きさをそろえて見ると、系統どうしは近い（1〜2B で 0.66〜0.73）。
- **種の床**：同じモデルの別の種の生成（A2-2 と A2-5・A2-6）では、T_m⁺ の差は Pythia-1B 0.033、Qwen2.5-0.5B 0.002、Qwen2.5-1.5B 0.005、SmolLM2-1.7B 0.031。0.03 くらいのぶれはありうる。比のばらつき 6.8% のうち、半分近くは種のぶれかもしれない。
- 指示に従うよう調整したモデル（-inst）は、元のモデルより T_m⁺ が 0.01〜0.02 低い（2 組だけ、種の床の中）。

## 5. 読み（後知恵）

- 「協同性の単位 n ≈ 2〜3 トークン」と「大きいモデルほど融点が低い」の 2 つは、どちらも決め方を変えても残った。とくに後者は、スケーリングの言葉で書ける最初の量（T_m⁺ が log N に沿ってまっすぐ下がる）。
- 大きいモデルほど「凍りにくい」のは、探索 8.12（大きいほど結晶が遅く始まる）とも合う。
- 次にやるなら：大きいモデルの T_m を 0.6 より下の温度まで含めて出す（T_m⁺ の偏りをなくす）。同じ大きさで、ΔH と n が大きさでどう動くか（ΔH_vH は Pythia で 9.3 → 5.1 と下がっている。n も変わるかは熱量計の ΔH が要る）。
