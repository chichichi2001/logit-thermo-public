## 3. 読み

- **T_m は T_0 よりずっと低い**：K ＝ 1（長い目で見て半分のトークンが結晶）は 0.53〜0.57。T_0（0.80〜0.91）では ln K ≈ −3（結晶は 5% くらい）。T_0 は「凍る温度」ではなく、「人の文章と同じくらいの液体になる温度」で、T_m とは別の温度だった。T_m と T_0 のあいだ（0.55〜0.85）は、凍ってはいないが人の文章より冷たい液体。
- **T_m ÷ T_0 が 3 モデルでそろう**：0.67・0.67・0.62。たまたまかもしれない（3 つしかない）。
- **協同性の単位は数トークン**：n ＝ 2.4〜3.3。作り物で n は 1.4 倍くらい大きめに出たので、本当は 2 前後かもしれない。結晶は「数十トークンの核がまとめて溶ける」のではなく、「2〜3 トークンずつ」溶けたり凍ったりしているように見える。ただし、写しの印は 4 トークンの組で決めるので、n ≈ 3 は印の大きさ（4 − 1）を映しているだけかもしれない。ここは今回の設計では切り分けられない。
- **ln K の直線は曲がっている**（2 次の係数が 3 モデルとも負）。温度の区間ごとの傾きは、0.4〜0.6 で 1.9〜2.6、0.6〜0.8 で 4.7〜6.9。温度が高いほど ΔH_vH が大きい（比熱 ΔC_p が正、のような形）。熱量計の ΔH も温度とともに上がる（0.9 → 1.7）。区間ごとの n は 2〜6。
- 出口の決め方の感度：出口 0.5（履歴なし）で T_m 0.51〜0.54・n 1.7〜2.4、出口 0.1 で T_m 0.55〜0.59・n 2.6〜3.7。言葉は変わらない。
- 記録：§0 の罠の割り算（熱量計の ΔH ÷ エントロピーの差）は 1.09〜1.16。生成した温度で測ったので 1 からは少しずれたが、T_m とも T_0 とも関係のない数だった。
